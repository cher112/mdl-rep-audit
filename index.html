Preliminary code for a University of Tokyo research proposal — 広域システム科学系, Prof. Shin Matsushima.  ·  GitHub repo

Idea

Extend NML/MDL latent-common-cause detection (CLOUD; Kobayashi–Miyaguchi–Matsushima, 2024) from raw variables to the learned concept directions of a frozen deep encoder. For a representation Z, label Y, and environment indicator E, a two-part-MDL codelength selects, per concept direction, among:

modelmeaning
z ⊥ Yno label information
z | Ylabel relation shared across environments → robust
z | Y,Elabel relation modulated by environment → spurious

Shortest codelength wins — no tuned threshold.

Caveats

A preliminary proof-of-concept: two-part Gaussian MDL (not exact NML); concept directions probed on the same sample; by MDL consistency the discrete winner behaves like a significance test at large n (hence the continuous rate + floor). It detects evidence of shortcut-like dependence under specified model classes, not causal identification.
